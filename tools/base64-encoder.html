What is Base64?

Base64 is a scheme for encoding binary or text data using only 64 printable ASCII characters. It's commonly used to embed data in places that only support text, such as email attachments, data URIs in CSS/HTML, and API tokens.

How this tool works

Encoding uses the browser's built-in Base64 conversion with UTF-8 support, so text with special characters and emoji encodes and decodes correctly. All conversion happens locally — nothing is sent to a server.
