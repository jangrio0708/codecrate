Supported Markdown syntax

This previewer supports headings (# through ###), bold and italic text, inline code and fenced code blocks, links, blockquotes, and unordered/ordered lists — the syntax used in most READMEs, forum posts, and documentation.

Why preview Markdown before publishing

Markdown renders differently depending on formatting details like blank lines and indentation. Previewing your text before publishing to GitHub, a blog, or a forum helps you catch formatting mistakes before they go live.
