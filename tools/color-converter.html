HEX, RGB, and HSL explained

HEX represents a color as a 6-digit hexadecimal code (e.g. #7c3aed), commonly used in CSS and design tools. RGB describes a color by its red, green, and blue intensity values from 0–255. HSL describes a color by hue (0–360°), saturation, and lightness percentages, which can be more intuitive for adjusting a color's brightness or vividness.

When you need to convert

Designers and developers often need to convert between these formats — for example, taking a HEX value from a design tool and converting it to HSL to easily create lighter or darker variants for a UI theme.
