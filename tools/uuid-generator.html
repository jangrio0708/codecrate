What is a UUID?

A UUID (Universally Unique Identifier) is a 128-bit identifier formatted as 32 hexadecimal digits, typically shown as five groups separated by hyphens (e.g. xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx). Version 4 UUIDs are generated using random numbers, and the chance of a collision is astronomically small.

Common uses

UUIDs are widely used as database primary keys, session tokens, file names, and unique identifiers in distributed systems where you need uniqueness without a central coordinating authority. This generator uses your browser's cryptographically secure random number generator.
