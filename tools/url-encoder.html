What is URL encoding?

URL encoding (percent-encoding) converts characters that aren't allowed in a URL — like spaces, ampersands, and non-ASCII characters — into a `%XX` format so they can be safely transmitted. This tool uses JavaScript's encodeURIComponent and decodeURIComponent, which handle full URI components including query parameters.

Common uses

URL encoding is essential when building query strings, passing data as URL parameters, or working with APIs that require encoded input. Decoding is useful for reading percent-encoded values from log files, browser address bars, or webhook payloads.
